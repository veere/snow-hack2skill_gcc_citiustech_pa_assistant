## PA Analyst Copilot — Build Plan

### What I verified first

**The iframe constraint is real and shapes everything.** Snowflake injects `X-Frame-Options: DENY` plus `Cross-Origin-Resource-Policy: same-origin` on SiS, SPCS *and* App Runtime, and the CSP is explicitly documented as non-configurable. You chose dual-target, so: **one codebase, two deploy paths.** `st.query_params` is GA in SiS (with a transparent `streamlit-` prefix), so `member_id` arrives identically in both modes.

**Grounding surfaces exist and work:**
- Cortex LLMs work via cross-region inference (`CORTEX_ENABLED_CROSS_REGION = ANY_REGION`). Correct name is `claude-sonnet-4-5` — verified. Only `llama3.1-8b` is native to Azure East US 2.
- Cortex Analyst returns the **generated SQL** + `verified_query_used` metadata. There is no 0-1 confidence score — the only confidence signal is whether a verified query matched. Citations must therefore be *constructed*, not read off a score.
- Cortex Search returns whatever metadata columns I put in the service. Citations are a **design output**, not automatic.

**Data density supports a per-member copilot:** 1,171 members, 995 with PA history, 532 with open PAs, avg 6.1 PAs and 24.6 timeline events each.

### Architecture

```
member_id (typed OR ?member_id= from iframe host)
        │
        ├─ Overview: 4 insight tiles + open-PA cards + SLA countdown   [direct SQL on SERVING views]
        │
        └─ Ask ──► router ──┬─ member/data question → Cortex Analyst (semantic view)
                            │        └─ source card: generated SQL, views touched, row count, run time
                            └─ regulation question → Cortex Search (regulatory corpus)
                                     └─ source card: doc title, citation id, section, URL, licence
```

Both paths terminate in a **mandatory source card**. No card ⇒ no answer rendered.
